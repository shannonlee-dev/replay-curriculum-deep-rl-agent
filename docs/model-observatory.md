# 모델 관전 HTML

프로젝트 루트의 `html_model.html`을 브라우저에서 열면 됩니다. 서버, 인터넷 연결, Python 설치 없이 생성된 기보를 볼 수 있습니다. 카드 이동, 효과음(기본 꺼짐), 재생·일시정지, 0.5–4배속, 타임라인, 기보 클릭 이동, 결과 바로 보기와 JSON 다운로드를 지원합니다.

## 모델 변경과 기보 재생성

`html_model.py`의 `html_model` 변수에 모델 경로를 하드코딩합니다. 상대 경로는 스크립트가 있는 프로젝트 루트를 기준으로 해석합니다. 이 프로젝트의 모델 폴더 이름은 `models/`입니다.

```python
html_model = "models/best_model.zip"
```

프로젝트 루트에서 실행합니다.

```bash
.venv/bin/python html_model.py
```

기존 학습 의존성을 사용하며 CPU에서 한 번 로드한 모델로 실제 대국을 생성합니다. `SEEDS`는 고정 시드 목록, `REVERSE_TARGET`은 후반 시작의 남은 카드 수입니다. 기본 출력은 전체 게임 3판과 R48 후반 시작 3판이며 성공한 판만 고르지 않습니다. HTML에 모든 기보·스타일·스크립트·한글 폰트를 포함합니다.

HTML은 생성 당시의 모델 스냅샷입니다. 모델이 추가 학습되거나 교체되면 위 명령을 다시 실행해야 반영됩니다. 하단에 모델 경로와 학습 스텝이 표시되고, 마우스를 올리면 SHA-256을 확인할 수 있습니다. JSON 다운로드에도 이 식별 정보가 포함됩니다.

## 조작

- 재생 버튼 또는 Space: 재생·일시정지
- 좌우 버튼 또는 ← / →: 한 수씩 이동
- Home / End: 처음 / 결과로 이동
- 타임라인과 기보 항목: 원하는 수로 이동
- 전체 게임 / 커리큘럼과 대국 선택: 시작 방식과 시드 변경
- 손패의 금색 테두리: 다음에 모델이 낼 카드

키보드 단축키는 선택 상자·버튼 등의 기본 키보드 조작을 방해하지 않도록 해당 요소에 포커스가 있으면 적용하지 않습니다. OS의 동작 줄이기 설정에서는 카드 비행 애니메이션을 생략합니다.

화면은 모델의 실제 행동을 재생하며 선택 이유나 승률을 추정하지 않습니다. 덱의 미래 순서는 표시하지 않습니다. R48은 48장짜리 별도 게임이 아니라 원래 게임에서 48장이 남은 상태입니다.

## 소스와 확인

- `html_model.py`: 실제 모델 추론, 프레임 기록, 단일 HTML 생성
- `web/replay.html`, `web/replay.css`, `web/replay.js`: 화면과 재생 동작
- `web/fonts/observatory-ko.woff2`: 화면에 필요한 글리프만 포함한 Noto Sans KR 서브셋
- `web/fonts/OFL.txt`: 폰트 라이선스. 생성된 HTML에도 포함됩니다.
- `tests/test_html_model.py`: 상태·행동·보충 카드·턴 기록 재현 및 안전한 JSON 삽입 검증

```bash
.venv/bin/python -m unittest discover -s tests -p test_html_model.py -v
```

한글 문구를 새로 추가할 때는 폰트 서브셋에도 해당 글리프를 포함해야 합니다. 포함되지 않은 글자는 시스템 한글 폰트로 표시됩니다.
